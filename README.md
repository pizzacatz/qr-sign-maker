# QR Sign Maker

Offline, single-file web app for printing a large QR code sign on Letter (8.5 × 11 in) paper.

**Use it:** https://pizzacatz.github.io/svg_sign_maker/ — or download `index.html` and open it locally. No network needed.

1. Load an SVG or PNG QR code (click, drag & drop, or paste).
2. Add optional top and bottom text; adjust sizes, font, margins.
3. Click **Save as PDF / Print** → choose *Save as PDF*, Letter, margins *None*, headers/footers off.

SVG QR codes stay vector in the PDF. Settings are remembered in your browser; **Reset to defaults** restores them.
